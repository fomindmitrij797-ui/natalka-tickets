Исправление обработки кнопок Telegram. Замените только check.py в корне репозитория GitHub, затем запустите Actions вручную. Кнопки обрабатываются не мгновенно: только при следующем запуске GitHub Actions. В логе Check tickets появится число полученных команд и строки об отправленных ответах. Не меняйте Secrets и workflow.
