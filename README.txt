ОБНОВЛЕНИЕ: КНОПКА «ПРОВЕРИТЬ БИЛЕТЫ»

1. В GitHub открой репозиторий natalka-tickets -> файл check.py.
2. Нажми Edit (карандаш), удали прежний код и вставь содержимое нового check.py из архива.
   Или загрузи файл check.py через Add file -> Upload files и замени старый.
3. Сохрани через Commit changes.
4. Открой GitHub -> Actions -> Check Natalka tickets -> Run workflow.
5. Отправь /start своему Telegram-боту.
6. Когда закончится ближайшая проверка, бот пришлет сообщение с кнопками
   «🔎 Проверить билеты» и «📊 Статус бота».
7. Нажатие кнопки обрабатывается при СЛЕДУЮЩЕМ запуске GitHub Actions
   (по расписанию приблизительно каждые 5 минут, возможны задержки).

Не меняй уже работающий workflow и не публикуй токен. Должны быть настроены
GitHub Secrets TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID.

Ограничения: скрипт проверяет доступность по признакам на билетной странице;
фактическое наличие мест гарантировать нельзя. Команда /check НЕ запускает
GitHub Actions сразу: это невозможно без постоянно работающего обработчика.
