# NATALKA: Telegram-бот для нескольких подписчиков

Публичный GitHub-репозиторий + бесплатный GitHub Actions, проверка по расписанию (запуски могут задерживаться).

## Как обновить текущего бота

1. Замените в репозитории корневой `check.py` содержимым одноимённого файла из архива.
2. Замените корневой `requirements.txt` — добавлена библиотека `cryptography`.
3. Измените существующий `.github/workflows/check-tickets.yml`:
   - `runs-on: ubuntu-24.04` (вместо `ubuntu-latest`);
   - в шаге `Save state` замените `git add state.json` на `git add state.json subscribers.enc`.
   Можно также заменить workflow целиком на файл из архива: он включает запуск по расписанию и вручную.
4. Ничего не меняйте в Secrets: `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` остаются прежними.
5. Actions → Check Natalka tickets → Run workflow, убедитесь, что все шаги зеленые.
6. Друзья открывают вашего Telegram-бота и отправляют `/start`. Подписка сохранится при очередном запуске GitHub Actions.

## Команды

- `/start` — подписаться и получить текущую проверку.
- `/stop` — отписаться.
- «🔎 Проверить билеты» / `/check` — получить результат последней проверки на очередном запуске.
- «📊 Статус бота» / `/status` — проверить подписку и результат.

## Конфиденциальность

`subscribers.enc` содержит **зашифрованные** Telegram chat ID и безопасен для публичного репозитория, пока ваш токен BotFather остаётся секретным. Ключ шифрования вычисляется из токена с помощью SHA-256 и Fernet. **При смене токена старый `subscribers.enc` не расшифруется:** потребуется удалить его и попросить друзей подписаться повторно. Не сохраняйте chat ID в `state.json`, не публикуйте токен.

## Ограничения

- GitHub Actions не даёт мгновенных ответов; запуск cron может быть отложен или пропущен.
- Бот оценивает видимость покупки по интерфейсу Intickets. Наличие билетов может быть определено неточно.
- При большом числе подписчиков и проверяемых ссылок выполнение может превысить лимит времени; для небольшой группы друзей обычно достаточно.
- Если сообщение Telegram не доставляется из-за блокировки бота, чат удаляется из подписчиков.
